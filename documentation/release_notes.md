# Version 1.1 draft

- The revised cross-match contains 949 ALMA sources and 949 distinct Fermi counterparts, compared with 965 rows and 962 distinct counterparts in v1.0.
- Thirteen sources have no measurements on or after 2013-01-01; three further duplicate counterpart candidates are excluded. No sources are added.
- Source identifiers for retained objects and the original 21 column names/order are preserved.
- MATCH_STATUS and COUNTERPART_NAME are appended, for 23 columns in total.
- Redshift handling, Band 3 flux aggregation and measured ALPHA36 follow the revised selection documented in sample_selection.md.
- This matching-focused distribution excludes luminosities, luminosity-sample flags, analysis code and raw/reanalysis datasets.
- No formal v1.1 release date is assigned.
